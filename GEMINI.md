# Project Rules & Guidelines for LUMINA

## Mandatory Instructions

1. **Artifact README Documentation Requirement**:
   - For ANY change, modification, or feature implemented across the LUMINA ecosystem (IoT car server, autonomous navigation driver, hardware diagnostics, or mobile companion app), ALWAYS write and update an artifact README file in `E:\Lumina-pothole-detection-main` (e.g., `AUTONOMOUS_HARDWARE_INTEGRATION_README.md` and related docs).
   - Keep `E:\Lumina-pothole-detection-main\README.md` updated with the latest subsystem references, API endpoints, and hardware pin mappings.

2. **Frequent GitHub Commits**:
   - Commit code changes to Git frequently with clear, descriptive commit messages.
   - Push commits to the remote repository (`origin/neel`) regularly to maintain continuous version control.
